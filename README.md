# 数学者のひらめき

中学・高校で新しい単元に入る最初の授業で使う、ブラウザの学習ゲームです。
生徒は現代の困りごとに直面し、歴史上の数学者と一緒に考えて、公式や記号を自分の手で完成させます。

- 一覧：`https://<GitHub のユーザー名>.github.io/hirameki/`
- 各話を直接開く：`…/hirameki/#napier`（`#negative`、`#sqrt`、`#gauss-sum` も同じ）

AI は使っていません。生徒が入力した文は、どこにも送られません。
保存するのは「クリア」の印だけで、その端末のブラウザの中に残ります。

## いまある話

| URL の # | 学年 | 単元 | 数学者 | ジャンル |
|---|---|---|---|---|
| `negative` | 中1 | 正負の数 | ブラーマグプタ | お店・お金 |
| `sqrt` | 中3 | 平方根 | クリストフ・ルドルフ | 建築・デザイン |
| `napier` | 高2 | 対数 | ジョン・ネイピア | 宇宙 |
| `gauss-sum` | 高2 | 数列（等差数列の和） | ガウス | 音楽ライブ |

## 画像の置き場所

画像は話ごとのフォルダに、決まった名前で置きます。まだ無い画像は、何の写真が入るかを書いた仮の枠が出ます。

```
img/<話の#>/portrait.webp   数学者の肖像（上半身が写っていて、顔がはっきりしたもの）
img/<話の#>/crisis.webp     困っている現場の写真（縦長 4:5）
img/<話の#>/solved.webp     解決した現場の写真（縦長 4:5）
```

肖像の切り出し位置（顔アイコン・上半身）は、各話のファイルの `person.face` と `person.bust` で調整します。

## 話の足し方

1. `episodes/` に、いまある話をまねて新しいファイルを作る（`HK.episode({...})` を1回呼ぶ）
2. `index.html` の下のほうに `<script src="episodes/新しい話.js"></script>` を1行足す
3. 台本の点検を動かす（下）
4. `js/core.js` の `HK.VERSION` を上げる

## 点検の動かし方

Node.js が入ったパソコンで、このフォルダの1つ上から次を実行します。

```bash
node hirameki/tools/check-episodes.js
```

```bash
node hirameki/tools/test-judge.js
```

- `check-episodes.js`：各話の台本を点検します（正答のボタンが1つだけか、パズルの正解が作れるか、人物ファイルのエピソードが2つか、など）。画像が無いのは「警告」で、失敗にはしません。
- `test-judge.js`：会話の判定（全角・半角、誤答と正答の順番）を点検します。
- ブラウザで URL の最後に `?test` を付けて開くと、画面の中の自己点検が動き、結果がコンソールに出ます。

## フォルダの中身

```
index.html          画面の器
css/style.css       見た目
js/                 共通の仕組み（会話・パズル・体験パーツ・エピローグなど）
episodes/           話のデータ（1話1ファイル）
img/                画像
tools/              点検の道具
docs/               設計図と計画書
```
