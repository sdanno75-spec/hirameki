# 9話目 設計図：確率（高1 数A・パスカル・eスポーツ）

骨組みは [2026-11-12-episode-skeleton.md](2026-11-12-episode-skeleton.md) の19場面に従う。

## なぜこの話か

- シリーズ候補表の「確率／パスカル＆フェルマー／eスポーツ」。
- 確率は、パスカルとフェルマーが「途中で止まった勝負の賞金をどう分けるか」（分配問題）を手紙で議論したところから始まった。**本物の歴史の問題を、そのまま今の大会に置きかえられる。**
- 「2勝1敗だから 2 : 1」という、だれもが思いつく答えがまちがい、という驚きがある。

## 本物の困りごと

- 校内eスポーツ大会の決勝。**先に3勝したほうが優勝**、賞金（商品券）は **12,000円**。
- A チームが **2勝**、B チームが **1勝** したところで、校舎の停電で中止。今日はもう再開できない。
- 賞金をどう分けるか、今日中に決めて発表しないといけない。両チームとも納得していない。
- よくある案
  - 半分ずつ：6,000円ずつ → A「2勝してるのに？」
  - 勝った数で 2 : 1：8,000円と 4,000円 → B「まだ逆転できたのに…」でも A も「優勝目前だったのに」
- 本物の計算：続けていたら、あと最大2試合。
  - 起こりうる続き：AA、AB、BA、BB（どれも同じくらい起こりやすい、と考える）
  - B が優勝するのは BB のときだけ → B の勝つ確率 1/4、A は 3/4
  - 賞金：A **9,000円**、B **3,000円**
  - （実際は AA・AB では2試合目はしないが、「2試合やったことにして数えても結果は同じ」ことも見せる）

## 流れ（骨組みの番号）

1. 導入：実行委員長「決勝、盛り上がってる！ A が 2勝、B が 1勝。あと 1勝で A の優勝だ」
2. 異変：停電。「校舎全体が止まった。今日はもう再開できないって…」
3. 本物の計算：「賞金 12,000円、どう分ける？ 両チームとも『自分たちが多くもらうべき』って言ってる」
4. 写真：真っ暗なステージで、ゲーム画面が消えたモニターと、言い合う両チームのメモ（「6000/6000？」「8000/4000？」と書いた紙）。
5. 見積もり talk「A が優勝する見込みは、どのくらいだと思う？」
   - 正答「B より大きいけど、決まってはいない」→「そう。でも、どのくらい大きいかで、分け方が変わる」
   - 誤答「もう決まりです」→「B が2連勝したら、B の優勝だよ？」
   - 誤答「五分五分です」→「A はあと1勝、B はあと2勝。同じかな？」
6. 数字で：「半分ずつ、2 : 1、全部 A…。案が3つあって、どれも誰かが怒ってる」
7. どうする talk（any）：「じゃんけんで決める」→「賞金をじゃんけんで？ 大会の意味がない…」／「全部 A にあげる」→「B はまだ逆転できたのに？」
8. 登場：消えたモニターが光る →「む…ここはどこだ？ 光る板の勝負が、途中で止まっておるな」→ 名乗る →「実は友人の騎士から、まさに同じ相談を受けたところでな。フェルマー君と手紙で議論しておる」
9. 一緒に確かめる（**新しい体験パーツ：続きを書き出す**）
   - 「次の試合」のカードを2回めくると、AA・AB・BA・BB の4通りが並ぶ（樹形図の形）。
   - それぞれの続きで、優勝がどちらかを色分けする → A が3つ、B が1つ。
10. 仲間の反応：委員長「4通りのうち3通りで A…！ 3 : 1 ってこと？」
11. 名づけ talk：「『起こりうる全部のうち、それが起こる割合』と毎回言うのは長いな…」
    - 正答：名前をつける →「起こりやすさを、0 から 1 の数で表そう。A の優勝は 3/4、B は 1/4」
    - 仲間「日本では、それを『確率』って呼ぶんだって」
12. 広げる talk：「では、A が 2勝、B が 0勝で止まっていたら？」→ 正答「A 7/8、B 1/8」（あと最大3試合、BBB のときだけ B）。誤答「A 2/3」には「続きを全部書き出してみよう」
13. パズル：`B の優勝 ＝ {0} 通り ÷ 4 通り`、`B の賞金 ＝ 12000 × {1}`
    - ブロック：1、3、1/4、3/4
    - 正解：1、1/4
    - 試算：B の賞金 ＝ 3,000円、A ＝ 9,000円、合計 12,000円
14. 現実に戻す：委員長「A 9,000円、B 3,000円。理由も説明できる！ 両チームとも『それなら』って言ってくれた」
15. こう変わる（how）
    - 半分ずつ：6,000 / 6,000 → A が納得しない
    - 勝った数で：8,000 / 4,000 → 「これまで」しか見ていない
    - 確率で：続きを書き出す AA・AB・BA・BB → A 3/4、B 1/4 → 9,000 / 3,000（「これから」を見ている）
16. 解決：写真が切り替わる（握手する両チーム）。
17. 説明 talk：誤答「勝った数で分けました」「なんとなく A を多めにしました」、正答「この先の4通りを書き出して、勝つ確率 3/4 と 1/4 で分けました」
18. 小話：「私は 19 歳のとき、父の税金の計算を手伝うために、歯車で足し算をする機械を作ったのだ」
19. 質問タイム・退場

## 質問タイム（この話の分）

- AA や AB のときは、2試合目をしないのに数えていいんですか？（→ してもしなくても優勝は決まっている。数えやすくするために「やったことにする」）
- 本当に、どの続きも同じくらい起こりやすいんですか？（→ 強さが同じ、と考えたとき。強さが違えば、確率も変わる）
- パスカルさんはどんな人ですか？
- 確率は今どこで使われていますか？（→ 天気予報の降水確率、ゲームのガチャ、保険、医療）
